# Package index

## All functions

- [`collapse_by_keys()`](collapse_by_keys.md) : Collapse duplicate key
  groups, concatenating selected columns and replacing other divergences
  with NA
- [`collapse_candidates()`](collapse_candidates.md) : Extract original
  rows from key groups where concatenation would be required
- [`collapse_concat_only()`](collapse_concat_only.md) : Collapse data
  and keep only key groups where concatenation occurs
- [`collapse_no_concat()`](collapse_no_concat.md) : Collapse data and
  keep only key groups where no concatenation is needed
