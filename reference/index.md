# Package index

## All functions

- [`collapse_by_keys()`](https://besibo.github.io/TableCleaneR/reference/collapse_by_keys.md)
  : Collapse duplicate key groups, concatenating selected columns and
  replacing other divergences with NA
- [`collapse_candidates()`](https://besibo.github.io/TableCleaneR/reference/collapse_candidates.md)
  : Extract original rows from key groups where concatenation would be
  required
- [`collapse_concat_only()`](https://besibo.github.io/TableCleaneR/reference/collapse_concat_only.md)
  : Collapse data and keep only key groups where concatenation occurs
- [`collapse_no_concat()`](https://besibo.github.io/TableCleaneR/reference/collapse_no_concat.md)
  : Collapse data and keep only key groups where no concatenation is
  needed
- [`normalize_num_list()`](https://besibo.github.io/TableCleaneR/reference/normalize_num_list.md)
  : Normalize a number list stored as a character string
